لا تعيد بناء التطبيق من الصفر.
لا تغيّر التصميم العام.
لا تغيّر الهوية البصرية الحالية.
لا تستخدم ألوان لحظي أو التصميم الأسود/الذهبي.

- أبيض
- كحلي #071B33
- برتقالي #FF7900
- رمادي فاتح للبطاقات

مهم جدًا:
لا تستخدم Supabase.
لا تستخدم Firebase.
لا تستخدم localStorage كنظام بيانات رئيسي.
لا تستخدم demo mode.
لا تستخدم fake data كنظام أساسي.
استخدم فقط النظام الحالي داخل Replit:
- PostgreSQL + Express API + Drizzle ORM للبيانات
- Replit Object Storage للصور والملفات

مهم جدًا:
لا تضف نظام طلبات للزبائن.
لا تضف Orders.
لا تضف Requests.
لا تضف حالات مثل assigned / completed / cancelled.
التطبيق ليس نظام إدارة طلبات.
طريقة عمل التطبيق فقط:
قسم → تخصص → مدينة/منطقة → فني أو شركة → واتساب أو اتصال.

لا تغيّر لوحة التحكم إلا في حدود المطلوب.
نفّذ تنظيم الأقسام والتخصصات فقط.

المطلوب:
أريد تنظيم تطبيق "اطلب فني" إلى أقسام رئيسية، وكل قسم تحته التخصصات المناسبة، وبعد اختيار التخصص تظهر قائمة الفنيين أو الشركات.

طريقة الاستخدام المطلوبة:
المستخدم يدخل التطبيق:
1. يرى الأقسام الرئيسية.
2. يختار القسم.
3. يرى تخصصات هذا القسم.
4. يختار التخصص.
5. يختار المدينة أو يرى الفنيين حسب المدينة.
6. يتواصل مع الفني أو الشركة عبر واتساب أو اتصال.

لا أريد عرض كل التخصصات في الصفحة الرئيسية دفعة واحدة لأنها أصبحت كثيرة.

--------------------------------------------------
ثالثًا: تعديل الصفحة الرئيسية
--------------------------------------------------

بدل عرض كل التخصصات في الصفحة الرئيسية، اعرض الأقسام الرئيسية فقط.

كل بطاقة قسم يجب أن تحتوي:
- أيقونة واضحة
- اسم القسم بالعربي أو الإنجليزي حسب اللغة
- عدد التخصصات داخل القسم
- سهم للدخول
- تصميم نظيف بنفس ألوان التطبيق

مثال البطاقة:
"خدمات منزلية"
"10 تخصصات"

"خدمات سيارات"
"10 تخصصات"

"بناء وتشطيب"
"9 تخصصات"

"تقنية وأمن"
"7 تخصصات"

"نقل وخدمات عامة"
"6 تخصصات"

"حدائق ومسابح"
"5 تخصصات"

أضف تحتها زر أو رابط:
"عرض كل التخصصات"

--------------------------------------------------
رابعًا: صفحة القسم
--------------------------------------------------

عند الضغط على أي قسم، افتح صفحة تعرض تخصصات هذا القسم فقط.

المسار المقترح:
sections/:sectionId

أو استخدم أي نظام routing موجود في المشروع.

المهم:
- صفحة القسم تعرض تخصصات القسم فقط.
- الضغط على التخصص يفتح الفنيين أو الشركات الخاصة بهذا التخصص.
- لا توجد صفحة فارغة.

--------------------------------------------------
خامسًا: صفحة كل التخصصات
--------------------------------------------------

أضف أو حافظ على صفحة:
"كل التخصصات"

تعرض كل التخصصات مجمّعة تحت الأقسام.

مثال:

خدمات منزلية
- كهرباء
- سباكة
- تكييف

خدمات سيارات
- ميكانيكي
- كهربائي سيارات
- سمكري

وهكذا.

--------------------------------------------------
سادسًا: نموذج "انضم معنا"
--------------------------------------------------

عدّل نموذج "انضم معنا" بحيث يكون الاختيار بهذا الترتيب:

1. نوع العمل:
- فرد / فني مستقل
- شركة / ورشة / فريق خدمات

2. القسم الرئيسي:
- خدمات منزلية
- خدمات سيارات
- بناء وتشطيب
- تقنية وأمن
- نقل وخدمات عامة
- حدائق ومسابح
- المزيد من الخدمات

3. التخصص:
يعرض فقط التخصصات التابعة للقسم المختار.

مثال:
إذا اختار "خدمات سيارات"، تظهر فقط:
- ميكانيكي سيارات
- كهربائي سيارات
- سمكري سيارات
- بنشر متنقل
- بطاريات سيارات
- تكييف سيارات
- ونش وسحب سيارات
- غسيل سيارات متنقل
- فحص كمبيوتر سيارات
- تبديل زيت وفلاتر

تأكد أن طلب الانضمام الذي يُرسل من نموذج "انضم معنا" يحفظ:
- workType
- sectionId
- sectionNameAr
- sectionNameEn
- categoryId
- categoryNameAr
- categoryNameEn

مهم:
هذه طلبات انضمام فنيين أو شركات فقط.
لا تنشئ طلبات زبائن.
لا تنشئ Orders.
لا تنشئ Requests.

--------------------------------------------------
سابعًا: لوحة التحكم
--------------------------------------------------

إذا كانت لوحة التحكم تحتوي على إدارة التخصصات، أضف للتخصص حقل:

sectionId

حتى يستطيع الأدمن معرفة كل تخصص تابع لأي قسم.

في صفحة إدارة التخصصات:
- أظهر القسم التابع له التخصص.
- عند إضافة تخصص جديد، يجب اختيار القسم.
- عند تعديل تخصص، يمكن تغيير القسم.

إذا كانت صفحة إدارة الأقسام غير موجودة، لا تبني لوحة كبيرة الآن.
فقط أضف بيانات الأقسام في PostgreSQL أو في النظام الحالي حسب الموجود.

إذا كان سهلًا وبدون تكلفة كبيرة، أضف صفحة بسيطة:
إدارة الأقسام

تحتوي:
- اسم القسم عربي
- اسم القسم إنجليزي
- ترتيب
- تفعيل / تعطيل

لكن لا تستخدم higher power mode.

--------------------------------------------------
ثامنًا: الأيقونات
--------------------------------------------------

استخدم الأيقونات الموجودة حاليًا إن وجدت.

إذا لم توجد أيقونة لخدمة جديدة، استخدم مؤقتًا:
more.png
أو
maintenance.png

ولا تعرض أي أيقونة مكسورة.

لا تستخدم صور خارجية.
لا تستخدم أيقونات من الإنترنت.
لا تستخدم Supabase.

لاحقًا سأرفع أيقونات مخصصة للتخصصات الجديدة.

--------------------------------------------------
تاسعًا: الحفاظ على التصميم
--------------------------------------------------

لا تستخدم تصميم لحظي الأسود/الذهبي.

حافظ على تصميم اطلب فني الحالي:
- خلفية بيضاء
- كحلي
- برتقالي
- بطاقات واضحة
- أيقونات كبيرة
- مناسب للموبايل

لا تجعل الصفحة مزدحمة.
الأقسام يجب أن تجعل التطبيق أنظف وأسهل.

--------------------------------------------------
عاشرًا: الفحص النهائي
--------------------------------------------------

بعد التنفيذ تأكد من التالي:

1. الصفحة الرئيسية تعرض الأقسام الرئيسية وليس كل التخصصات دفعة واحدة.
2. كل قسم يفتح صفحة تخصصاته.
3. كل تخصص يفتح صفحة الفنيين أو الشركات الخاصة به.
4. التخصصات القديمة لم تختفِ.
5. تخصصات السيارات أُضيفت.
6. نموذج "انضم معنا" يعرض القسم ثم التخصص.
7. لا توجد أيقونات مكسورة.
8. لا توجد صفحات فارغة.
9. لا توجد أخطاء في Console.
10. لا توجد تغييرات غير مطلوبة في التصميم.
11. لا توجد تغييرات في لوحة التحكم إلا الضروري.
12. لا يتم استخدام Supabase.
13. لا يتم إنشاء Orders أو Requests للزبائن.
14. التطبيق يبقى قائمًا على واتساب أو اتصال مباشر فقط.

توقف بعد تنفيذ هذه المهمة فقط.

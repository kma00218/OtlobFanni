نفّذ المطلوب التالي بدقة في تطبيق "اطلب فني".

المهم الآن:
أريد لوحة تحكم تجريبية كاملة Demo Admin Panel حتى أستطيع فحص التطبيق والتأكد أن كل شيء يعمل قبل ربط Supabase وقاعدة البيانات الحقيقية.

مهم جدًا:
- لا تعيد بناء التطبيق من الصفر.
- لا تغيّر فكرة التطبيق.
- لا تغيّر التصميم العام للتطبيق إلا عند الضرورة.
- لا تضف ميزات خارج المطلوب.
- لا تستخدم Firebase.
- لا تستخدم Backend منفصل.
- لا تجعل التطبيق يتوقف إذا Supabase غير مربوط.
- نفّذ المطلوب فقط.

--------------------------------------------------
أولًا: Demo Admin Mode
--------------------------------------------------

إذا كانت مفاتيح Supabase غير موجودة:

VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY

يجب أن يعمل التطبيق في وضع تجريبي Demo Mode.

في صفحة:

/admin/login

أظهر زر واضح:

"دخول تجريبي للوحة التحكم"
"Demo Admin Login"

عند الضغط عليه:
- يدخل المستخدم كـ Super Admin تجريبي.
- يحفظ حالة الدخول محليًا فقط لأغراض الفحص.
- يفتح:
  /admin/dashboard

أضف في أعلى لوحة التحكم شارة صغيرة برتقالية:
"Demo Mode"

مهم:
Demo Mode فقط للفحص.
لا يحتاج Supabase.
لا يحفظ بيانات حقيقية.
لا يستدعي Supabase إذا المفاتيح غير موجودة.
لا يظهر أخطاء Supabase في Console.

ثانيًا: الدخول المخفي للوحة التحكم

--------------------------------------------------
ثامنًا: صفحة انضم لنا كفني
--------------------------------------------------

أنشئ أو أصلح صفحة:

/join

العنوان:
"انضم لنا كفني"
"Join as Technician"

النموذج يحتوي:

1. الاسم الكامل
2. رقم الهاتف
3. رقم الواتساب
4. المدينة
5. المنطقة
6. التخصص
7. سنوات الخبرة
8. السعر يبدأ من
9. هل تقدم كشف؟
10. مناطق الخدمة
11. أيام وساعات العمل
12. هل تعمل طوارئ؟
13. وصف مختصر عن الخبرة
14. صور أعمال سابقة، اختيارية
15. رابط صفحة فيسبوك أو واتساب بزنس، اختياري
16. ملاحظات إضافية

عند الإرسال في Demo Mode:
- أضف الطلب إلى قائمة الفنيين بحالة:
  application_status = pending
  source = application
  is_approved = false
  is_active = false
  status = inactive

أظهر رسالة نجاح:

"تم إرسال طلبك بنجاح. سيتم مراجعته من الإدارة قبل ظهوره في التطبيق."

بالإنجليزية:
"Your application has been submitted successfully. It will be reviewed by the admin before appearing in the app."

مهم:
طلب الفني لا يظهر في التطبيق العام إلا بعد موافقة الأدمن.

السابع عشر: التطبيق العام
--------------------------------------------------

التطبيق العام يجب أن يعمل حتى بدون Supabase.

إذا لا توجد قاعدة بيانات:
- استخدم بيانات Demo أو local fallback.
- لا تظهر أخطاء.
- إذا لا يوجد فنيين في تخصص معين، اعرض:
"لا يوجد فنيون متاحون حاليًا في هذا التخصص."

اعرض فقط الفنيين الذين:
is_active = true
is_approved = true
status != inactive

--------------------------------------------------
التاسع عشر: لاحقًا Supabase
--------------------------------------------------

جهّز الكود بحيث إذا أضفت لاحقًا:

VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY

يستطيع التطبيق استخدام Supabase.

لكن الآن يجب أن يعمل Demo Mode بدون Supabase.

لا تظهر رسالة خطأ مزعجة بسبب غياب Supabase.
بدل ذلك أظهر داخل لوحة التحكم:
"Demo Mode: Supabase is not connected yet."

--------------------------------------------------
العشرون: الفحص النهائي
--------------------------------------------------

قبل أن تقول Done، تأكد من الآتي:

1. التطبيق العام يفتح.
2. الضغط خمس مرات على الشعار يفتح /admin/login.
3. زر Demo Admin Login يعمل.
4. /admin/dashboard يفتح.
5. كل صفحات لوحة التحكم تفتح.
6. صفحة الفنيين تعمل.
7. يمكن إضافة فني يدويًا في Demo Mode.
8. صفحة /join تعمل.
9. الفني يستطيع إرسال طلب انضمام.
10. الطلب يظهر في لوحة التحكم كـ pending.
11. الأدمن يستطيع قبول الطلب.
12. بعد القبول يظهر الفني في التطبيق العام.
13. الأدمن يستطيع رفض الطلب.
14. الطلب المرفوض لا يظهر في التطبيق العام.
15. صفحة المدن تعمل.
16. صفحة التخصصات تعمل.
17. صفحة الطلبات تعمل.
18. صفحة الإعلانات تعمل.
19. صفحة المستخدمين تعمل.
20. صفحة الإعدادات تعمل.
21. صفحة السجلات تعمل.
22. لا توجد Console errors.
23. لا توجد صفحات فارغة.
24. لا تظهر أخطاء Supabase عندما لا تكون المفاتيح موجودة.
25. لا تغيّر أي شيء خارج المطلوب.

نفّذ الآن.

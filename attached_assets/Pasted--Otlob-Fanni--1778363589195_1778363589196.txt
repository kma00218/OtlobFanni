أريد بناء تطبيق ويب كامل باسم "اطلب فني" / "Otlob Fanni" كتطبيق خدمات فنية في ليبيا.

الهدف:
تطبيق بسيط وسريع ورخيص التشغيل، يعمل كـ Web App، عربي وإنجليزي، يساعد المستخدم على اختيار نوع الخدمة الفنية ثم التواصل مباشرة مع الفني عبر واتساب أو اتصال.

مهم جدًا لتقليل تكاليف Replit:
- لا تستخدم Backend.
- لا تستخدم Firebase.
- لا تستخدم Supabase.
- لا تستخدم Database خارجية.
- لا تستخدم API خارجي.
- لا تستخدم Google Maps.
- لا تستخدم تسجيل دخول.
- لا تستخدم دفع إلكتروني.
- لا تستخدم مكتبات كثيرة.
- اجعل كل البيانات داخل ملفات JavaScript محلية.
- يجب أن يعمل التطبيق مباشرة بعد التشغيل بدون أي إعدادات إضافية.

التقنيات المطلوبة:
- React
- Vite
- Tailwind CSS
- React Router DOM فقط للتنقل بين الصفحات
- Lucide React للأيقونات فقط

اتجاه اللغة:
- اللغة الافتراضية عربية RTL.
- عند اختيار الإنجليزية يتحول التطبيق إلى LTR.
- أضف زر واضح لتبديل اللغة AR / EN.
- جميع النصوص يجب أن تكون مترجمة عربي/إنجليزي.

الشعار:
سأرفق صورة الشعار.
ضع الشعار في أعلى الصفحة الرئيسية بشكل كبير وواضح.
إذا لم تستطع استخدام الصورة المرفقة، استخدم شعار نصي بديل:
"اطلب فني"
بالكحلي والبرتقالي، مع أيقونة تجمع بين location pin و wrench.

طريقة عمل التطبيق:
- عند الضغط على أي تخصص، انتقل إلى صفحة الفنيين لهذا التخصص.
- في صفحة الفنيين، اعرض قائمة فنيين تابعين لهذا التخصص فقط.
- عند الضغط على بطاقة فني، افتح صفحة تفاصيل الفني.
- في تفاصيل الفني أظهر:
  - الاسم
  - التخصص
  - المدينة
  - التقييم
  - عدد سنوات الخبرة
  - حالة الفني: متاح الآن / مشغول
  - السعر التقريبي يبدأ من
  - وصف مختصر
  - أزرار واضحة:
    واتساب
    اتصال

متطلبات التصميم:

- أزرار كبيرة وواضحة.
- الأيقونات تكون بنفس لون الهوية.
- لا تجعل التصميم مزدحمًا.
- اجعل التطبيق مناسبًا للهاتف أولًا.
- يجب أن يظهر بشكل جيد أيضًا على الكمبيوتر.
- استخدم خط عربي واضح من النظام، ولا تضف خطوط خارجية.
- لا تستخدم صور خارجية من الإنترنت.

- اجعل التصميم قريبًا من الصورة المرجعية: شعار كبير في الأعلى، وأسفله أيقونات التخصصات، ثم زر طلب فني.

- لا تستخدم بيانات ناقصة.
- لا تستخدم console errors.

- لا تجعلني أحتاج لتعديل أي ملف يدويًا.
- لا تسألني أسئلة إضافية.

- بعد الانتهاء شغّل المشروع وتأكد أنه يعمل.
